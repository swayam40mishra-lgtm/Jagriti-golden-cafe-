Deploy with the existing Vercel-connected GitHub repository
1. Extract this ZIP.
2. Replace the repository's index.html, styles.css, and script.js with these files.
3. Upload the assets/jaagrit-logo.png file to the repository's assets folder (create the folder if it does not exist).
4. Commit the changes to the branch connected to Vercel. Vercel should build from that commit using the project's existing deployment settings.
5. Open the deployed URL on mobile and desktop and check the menu filters, navigation, WhatsApp link, Instagram link, and map search.
